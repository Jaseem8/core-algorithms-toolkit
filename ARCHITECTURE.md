# Architecture & Complexity Specifications

## Theoretical Complexity Bounds
| Data Structure / Algorithm | Operation | Time Complexity | Space Complexity |
| :--- | :--- | :--- | :--- |
| `LRUCache` | `get()` / `put()` | $O(1)$ | $O(N)$ |
| `Dijkstra` | `shortest_path()` | $O((V + E) \log V)$ | $O(V)$ |
| `Trie` | `insert()` / `search()` | $O(L)$ | $O(\Sigma \cdot L)$ |
| `TokenBucket` | `consume()` | $O(1)$ | $O(1)$ |
